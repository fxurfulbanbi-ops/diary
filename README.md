# 📔 Приватний щоденник

Сайт: `https://fxurfulbanbi-ops.github.io/diary/`
Записи шифруються вашим паролем прямо в браузері (AES-256) і зберігаються в **приватному** репозиторії `diary-data`. Пароль нікуди не надсилається. **Якщо забудете пароль — записи відновити неможливо.**

## Налаштування (один раз)
1. Створіть **приватний** репозиторій `diary-data`: https://github.com/new (Private, можна поставити галочку «Add a README»).
2. Створіть токен: https://github.com/settings/personal-access-tokens/new
   - Token name: `diary`; Expiration: до 1 року (потім створите новий).
   - Repository access: **Only select repositories** → `diary-data`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Натисніть **Generate token** і скопіюйте його (`github_pat_...`).
3. Відкрийте сайт, вставте токен, придумайте пароль щоденника (не такий, як від GitHub) і натисніть «Зберегти й відкрити».
4. На телефоні — те саме: той самий токен і **той самий пароль**.

## Безпека
- Токен зберігається на пристрої лише зашифрованим вашим паролем.
- Щоденник блокується через 5 хв бездіяльності (або 1 хв у фоні).
- «Забути цей пристрій» на екрані входу видаляє токен з пристрою.
